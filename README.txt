                             AllBinary Platform Julia

What is it?

This repository contains code generated by the AllBinary Platform for support in Julia.  
This repo is used to allow developers to skip the Julia code generation step.

What are some example games with this Julia code?

https://allbinary.itch.io (The downloads with "-julia" in the filename are Julia only builds. Currently that only includes nothing. Also the Julia builds are not available on Google Play or other stores.)
